### 实现方式（v2 完全重写）
- Python `markdown` 库转换（extensions: tables, fenced_code, sane_lists，**移除 nl2br** 避免多余 `<br>`）
- **MathJax 3.x**（CDN）渲染数学公式，支持 `\tag{}` 公式编号
- **数学公式保护机制**：转换前用正则提取 `$$...$$` 和 `$...$`，替换为占位符，防止 markdown 破坏 LaTeX 语法（`_` `*` 等），转换后恢复
- 字体：楷体（KaiTi）正文 + 黑体（SimHei）标题 + Fira Code 代码
- 暖色调纸质书配色（#faf8f5 页面背景、#fffef9 卡片背景）
- 章节卡片布局（box-shadow + border-radius: 12px）
- 段落首行缩进 2em（引用块/列表/代码块不缩进）

### 产出文件
- `build_book.py` — 生成脚本（v2 完全重写，约 32KB）
- `multi-factor-quant-book.html` — 最终 HTML（约 389KB，含 20 章、32 代码块、45 表格、174 个 display 公式、794 个 inline 公式）

### HTML 特性
- 左侧 sticky 侧边栏目录（h1 + h2 两级，IntersectionObserver 自动高亮）
- 页头渐变背景（深蓝→藏蓝）+ 金色渐变标题
- 页脚版权信息 + 生成日期 + 源文件列表
- 回到顶部按钮（金色圆形）
- 响应式：PC（flex 布局）/ 平板（220px 侧边栏）/ 手机（抽屉式菜单 + 汉堡按钮）
- 打印样式（隐藏目录和按钮，正文全宽）
- 暗色模式（prefers-color-scheme: dark）
- CSS 自定义属性统一管理配色和尺寸
