### 实现方式
- 使用 Python `markdown` 库将 MD 转 HTML（extensions: tables, fenced_code, toc, nl2br, sane_lists）
- KaTeX 渲染数学公式（$$...$$ 和 $...$ 定界符）
- highlight.js 渲染代码高亮（atom-one-light 主题）
- 自定义 CSS：左侧固定侧边栏目录 + 右侧正文，阅读友好排版

### 产出文件
- `build_book.py` — 生成脚本（可复用，修改 CHAPTERS 列表即可适配其他书籍）
- `multi-factor-quant-book.html` — 最终 HTML（约 394KB，含 20 章、33 代码块、45 表格、87 个 display 公式）

### HTML 特性
- 侧边栏目录（含二级标题子目录）
- 阅读进度条
- 当前章节高亮
- 返回顶部按钮
- 响应式设计（移动端适配）
- 打印优化

### 修复：目录锚点错位 bug
`build_toc` 提取标题时包含了 h1，但 `process_markdown_content` 只对 h2/h3 编号（h1 被 `build_content` 去掉），导致目录链接整体偏移 1。修复方法：`build_toc` 中跳过 h1 且不递增 global_idx，同时改为遍历所有 h2+h3 来正确计算全局索引（而非只遍历 h2 独立编号）。

### 前言重新设计
用户删掉了 README.md 大部分内容，要求重写一个"看起来像靠谱的书"的前言。新前言包含：题记（引用块）、关于这本书（定调+目标读者）、这本书讲什么（五篇内容概述）、这本书不讲什么（边界界定）、如何阅读这本书（阅读路径建议）、配套资源、结语。语言风格正式有温度，去掉了原来技术文档式的目录结构说明。
