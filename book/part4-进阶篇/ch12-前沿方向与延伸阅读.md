## 12.1 线性模型的天花板：为什么需要机器学习

### 12.1.1 线性假设的三个局限

回顾第3章的核心模型：$E[r_i | f_1, f_2, ..., f_K] = \alpha + \sum_{k=1}^K \beta_k f_k$

这个模型隐含三个假设：

**假设1：每个因子的效果是"全局线性"的**

线性模型认为EP每高0.01，收益就多0.5%，不管EP是从0.02到0.03（极端高估区域）还是从0.15到0.16（极端低估区域）。但实证研究发现，EP因子的效果高度集中在极端值：
- EP最高的10%股票（极端低估值）：月均超额 +2.5%
- EP中间80%的股票：几乎没有区分度（±0.3%）
- EP最低的10%股票（极端估值偏高）：月均超额 -1.8%

这是一个"两头强、中间弱"的非线性模式。线性模型会把极端值的强信号"平均"到所有区域，导致整体IC看起来只有0.03-0.04，严重低估了因子在极端值处的预测能力。

**假设2：因子之间没有交互效应**

线性模型假设EP和动量的贡献是"各自独立、简单相加"的。但真实情况中，因子组合可能产生"1+1>2"或"1+1<0"的效应：

- "低EP + 高动量"的股票（低估值且在涨）：月均超额可能高达3%，远超两个因子单独贡献之和（0.5%+0.4%=0.9%）
- "低EP + 低动量"的股票（低估值但在跌）：可能是"价值陷阱"，公司基本面在恶化，低估值是有原因的，未来继续跌
- "高EP + 高动量"（估值偏高且在涨）：追涨的"赛道股"，短期可能还涨，但长期风险极大

这种**交互效应**线性模型完全捕捉不到。你需要加入交叉项 $f_1 \times f_2$，或者使用天然能建模交互的非线性方法（如决策树）。

**假设3：因子效果不随市场环境变化**

线性模型用一个固定的 $\beta$ 描述因子效果，但现实是因子效果会随市场环境剧烈切换。2016-2017 年大盘股价值风格占优，价值因子的预测力很强；2020-2021 年赛道股和成长风格主导，价值因子几乎失灵；2022 年之后随着市场风险偏好下降，价值因子又开始恢复预测力。线性模型只能给你一个"全期平均"的 $\beta$，它无法判断当前处于哪种环境，也就无法在这三种环境下给价值因子不同的权重。你需要一个能"看环境下菜碟"的模型，这正是条件模型（如随机森林、LSTM）的强项。

### 12.1.2 机器学习能做什么：从"特征工程"到"关系发现"

在传统线性框架中，所有的"非线性建模"负担都落在**特征工程**上，你需要人工构造交叉项（$EP \times MOM$）、分段变量（$\mathbb{1}[EP > 0.1]$）、滞后变量等。这要求研究者有极强的领域直觉，且工作量巨大。

机器学习的核心价值在于：**它自动化了"关系发现"的过程**。你只需要把原始因子值扔进模型，它会自动找到哪些因子组合在什么条件下能预测收益，无需你事先猜测关系的形式。

但这里有一个深刻的权衡：**自动发现能力越强，过拟合风险越大**。线性模型只有 $K$ 个参数（因子数），不容易过拟合；而一个深层神经网络可能有上百万参数，极容易记住训练数据的噪声。如何在"表达能力"和"泛化能力"之间找到平衡，是ML在量化中的核心挑战。

## 12.2 决策树与集成方法：随机森林和XGBoost

### 12.2.1 决策树的直觉

决策树是最容易理解的非线性模型。它的逻辑就像一个"投资决策流程图"：

```
是否 EP > 0.08？
├── 是 → 是否 动量 > 0？
│        ├── 是 → 预测收益 +2.5%（低估值且在涨）
│        └── 否 → 预测收益 +0.3%（低估值但在跌，可能是价值陷阱）
└── 否 → 是否 ROE > 20%？
         ├── 是 → 预测收益 +1.8%（估值偏高但质量好）
         └── 否 → 预测收益 -0.5%（又估值偏高又差）
```

每个"节点"是一个简单的比较（$f_k > \text{阈值}$？），每条"路径"对应一种因子组合模式。决策树天然能捕捉非线性（阈值效应）和交互效应（不同路径=不同因子组合）。

**为什么单棵决策树不够用？** 因为它极易过拟合，深度不限的决策树可以完美拟合任何训练数据（包括噪声），但在新数据上表现很差。解决办法是**集成学习**：训练很多棵"不太好"的树，然后取平均（或投票），让它们的错误互相抵消。

### 12.2.2 随机森林：用"委员会投票"降低过拟合

**核心思想**：训练 $B$ 棵决策树（通常 $B = 500 \sim 2000$），每棵树在略有不同的数据子集上训练（Bagging），最终预测取所有树的平均值。

**关键机制**：

1. **Bootstrap采样**：每棵树只用全部训练数据的~63%（有放回采样），剩余37%作为"袋外"验证数据
2. **随机特征子集**：每个节点分裂时，不看全部 $K$ 个因子，而是随机选 $\sqrt{K}$ 个候选。这确保不同树"专注于"不同的因子组合
3. **取平均**：最终预测 = $\frac{1}{B}\sum_{b=1}^B T_b(\mathbf{x})$

**为什么有效？** 单棵树有高方差（过拟合），但偏差低（能拟合复杂关系）。$B$ 棵独立的树取平均后，方差减为 $\sigma^2/B$（类似分散投资降低风险），而偏差不变。这就是"委员会"的力量，每个成员可能犯错，但集体决策更可靠。

**在因子投资中的应用**：

输入：每只股票的 $K$ 个因子值（EP、动量、ROE（净资产收益率）、市值、波动率等）
输出：预测的下月收益（或收益排名）
训练：用历史数据的"因子值→次月收益"对训练森林

**相比线性模型的增益**：
- 自动捕捉"EP只在极端值有效"的阈值效应
- 自动发现"低EP+高动量"的协同效应
- 袋外误差（OOB Error）提供免费的样本外验证

**一个具体例子：三棵树给同一只股票打分**

> ⚠️ **示意性数据**：以下数字为说明随机森林投票机制而构造，非真实数据。

假设我们要预测股票 A 的下月收益排名，森林里有 3 棵树（真实场景是几百上千棵，这里简化）。股票 A 的因子值是：**EP 排名前 10%、动量排名前 30%、市值排名后 20%（小盘）**。三棵树因为训练数据子集和随机特征子集不同，各自看到的因子和判断路径也不同。下表汇总了三棵树的输入、决策结构和结果，树中的 `★` 标出了股票 A 实际走的分支和最终落入的叶子。

| 输入 | 决策结构 | 落入的叶子 | 决策结果 |
|:---:|---|------|:---:|
| EP + 市值 | <pre>  [EP&lt;20%?]<br>   /     \\<br> 是★      否<br>  │        │<br>[市值      叶子:<br>&gt;80%?]   +0.5%<br> /  \\<br>是    否★<br>│      │<br>叶子   叶子<br>-1%   +3%★</pre> | 低估值小盘 | **+3%** |
| 动量 + EP | <pre> [动量&lt;50%?]<br>   /     \\<br> 是★      否<br>  │        │<br>[EP       叶子:<br>&lt;30%?]   -0.5%<br> /  \\<br>是★   否<br>│      │<br>叶子   叶子<br>+1.5%★ 0%</pre> | 估值动量兼具 | **+1.5%** |
| 市值 + 动量 | <pre>[市值&gt;70%?]<br>   /     \\<br> 是★      否<br>  │        │<br>[动量      叶子:<br>&lt;60%?]   -0.5%<br> /  \\<br>是★   否<br>│      │<br>叶子   叶子<br>+2%★  +0.5%</pre> | 小盘趋势 | **+2%** |

森林的最终预测就是三者平均：$(3\% + 1.5\% + 2\%) / 3 = 2.17\%$。

这个例子揭示了随机森林的核心：**没有任何一棵树看到全部因子，但集体平均后反而更稳健**。如果只用树 1，你会过度依赖"小盘"这个信号（万一这个月小盘暴跌就惨了）；但三棵树里只有两棵重视小盘，平均之后小盘的影响被稀释了。这就是"委员会投票"降低方差的直观含义。

**实践经验**：随机森林相比线性 IC 加权，在因子间存在非线性关系或交互效应时能带来一定的 IC 提升。但提升幅度不是无限的，因为 A 股约 3000 只股票乘以有限的月份数，有效数据量并不大，模型容易过拟合。是否真能带来稳定提升，必须在你自己的数据上用 Walk-Forward 样本外验证来确认。

### 12.2.3 XGBoost/LightGBM：梯度提升的力量

> 📌 **本节要解决的问题**：梯度提升树如何在不显著过拟合的前提下拟合非线性关系？XGBoost在传统梯度提升基础上做了什么改进？
>
> **我们的做法**：串行训练每棵树拟合前一棵的残差，并在目标函数中加入正则项惩罚树复杂度
>
> **得到的结论**：XGBoost通过正则化目标函数控制树复杂度，以可控训练误差换取更优泛化能力；浅树低学习率配大量树是金融数据最稳健的配置
>
> 以上是结论，以下为推导，读者可自行选择是否跳过该推导过程，继续阅读 12.3.1 节。

随机森林通过"并行训练独立的树"来降低方差。梯度提升（Gradient Boosting）走的是另一条路：**串行训练，每棵新树专门修正前面树犯的错误**。

**核心思想**：

1. 用第1棵树拟合收益 $r$，得到残差 $e_1 = r - T_1$
2. 用第2棵树拟合残差 $e_1$，得到新残差 $e_2 = e_1 - \eta \cdot T_2$（$\eta$ 是学习率）
3. 用第3棵树拟合 $e_2$...
4. 最终预测 = $T_1 + \eta T_2 + \eta T_3 + ...$

**先理解"学习率"是什么**。学习率 $\eta$ 是一个 0 到 1 之间的小数，它控制"每棵新树的修正意见，我们采纳多少"。打个比方：你在射箭，第一箭偏左了 2 环，教练说"往右调 3 环"。如果你完全照做（学习率=1），可能一下子又偏到右边去了，因为教练的判断本身也有误差。稳妥的做法是每次只按教练意见的一半来调（学习率=0.5），多调几次慢慢逼近靶心。学习率越小，每一步越谨慎，需要的树越多，但最终越不容易被单棵树的"过度自信"带偏。这就是为什么金融数据（噪声大）要用小学习率。

**一个具体例子：三棵树逐步修正误差**

> ⚠️ **示意性数据**：以下数字为说明梯度提升的残差修正机制而构造，非真实数据。

假设股票 B 的真实次月收益是 **+5%**，学习率 $\eta = 0.5$（为看得清楚而特意设大，实际中更小）。股票 B 的特征：EP 排名前 15%、动量排名前 40%、市值中等。三棵树**串行**训练，注意每棵树预测的目标不同：第 1 棵预测收益本身，第 2、3 棵预测"上一步还差多少"（残差）。`★` 标出股票 B 走的分支。

第 1 棵树（预测收益 $r$，目标 +5%）：

```
        [EP 排名 < 20%？]
         /          \
       是★            否
        │              │
   叶子: +2% ★      叶子: -1%
   ← 股票B落这里
```

第 1 棵树给出 +2%，离真实的 +5% 还差 **3%**。这个 3% 就是"残差 $e_1$"，交给第 2 棵树去补。

第 2 棵树（预测残差 $e_1$，目标 +3%）：

```
       [动量排名 < 50%？]
         /          \
       是★            否
        │              │
   叶子: +2.8% ★    叶子: -0.5%
   ← 股票B落这里
```

第 2 棵树认为该补 +2.8%，但我们乘以学习率的系数：$0.5 \times 2.8\% = 1.4\%$。累计预测变成 $2\% + 1.4\% = 3.4\%$，离 +5% 还差 **1.6%**（新残差 $e_2$）。

第 3 棵树（预测残差 $e_2$，目标 +1.6%）：

```
       [市值排名 中等？]
         /          \
       是★            否
        │              │
   叶子: +1.5% ★    叶子: +0.3%
   ← 股票B落这里
```

第 3 棵树认为该补 +1.5%，乘以学习率：$0.5 \times 1.5\% = 0.75\%$。累计预测变成 $3.4\% + 0.75\% = 4.15\%$。

把这个过程列成表，一眼看清"逐步逼近"：

| 步骤 | 该树预测 | 采纳量（×η） | 累计预测 | 离真实 +5% 还差 |
|------|---------|-------------|---------|----------------|
| 第 1 棵树 | +2% | +2%（首棵全额） | 2% | 3% |
| 第 2 棵树 | +2.8% | +1.4% | 3.4% | 1.6% |
| 第 3 棵树 | +1.5% | +0.75% | 4.15% | 0.85% |

累计预测 2% → 3.4% → 4.15% 一步步逼近真实的 5%。这就是梯度提升的核心：**每棵新树不是重新预测收益，而是专门修正前面所有树加起来还没说对的那部分**。对比随机森林（大家独立投票、结果取平均），梯度提升是"接力赛"，后一棵树站在前面所有树的肩膀上补漏。

回到学习率：如果 $\eta = 1$（每次全额采纳），第 2 棵树会一步跳到 $2\% + 2.8\% = 4.8\%$，看似更快，但树的预测本身有噪声，全额采纳容易把噪声也学进去、来回震荡。$\eta$ 小则每步谨慎，需要更多树，但泛化更好，这正是"浅树 + 低学习率 + 大量树"配置的由来。

**XGBoost的核心创新**（Chen & Guestrin, 2016）：

在传统梯度提升基础上加入了**正则化项**，惩罚树的复杂度（叶节点数和叶节点权重）。目标函数变成：

$$\text{Obj} = \sum_{i=1}^N L(y_i, \hat{y}_i) + \sum_{b=1}^B \Omega(T_b) \tag{12.1}$$

其中正则化项 $\Omega(T)$ 定义为：

$$\Omega(T) = \gamma \cdot |\text{叶节点数}| + \frac{\lambda}{2}\sum_j w_j^2 \tag{12.2}$$

这个正则项的作用是：**即使某个复杂的树能进一步降低训练误差，如果它的复杂度太高（叶节点太多或权重太大），也会被惩罚掉**，用可控的训练误差换取更好的泛化能力。

**LightGBM**（Microsoft, 2017）是XGBoost的加速版本，用直方图近似和叶子优先生长策略，训练速度快5-10倍，特别适合大规模因子数据（3000只股票×100+因子）。

**XGBoost 和 LightGBM 的关系** 不是同一个软件，但是同一类算法。两者都实现了"带正则化的梯度提升树"这个核心思想（就是上面例子里那套"逐步修正残差 + 惩罚树复杂度"的逻辑），区别在工程实现上：

| | XGBoost | LightGBM |
|---|---------|----------|
| 开发者 | 陈天奇等（2016） | 微软（2017） |
| 树生长方式 | 按层生长（level-wise），每层所有节点一起分裂 | 按叶生长（leaf-wise），优先分裂收益最大的叶子 |
| 训练速度 | 较慢 | 快 5-10 倍（直方图优化） |
| 内存占用 | 较高 | 较低 |
| 小数据表现 | 稳健 | 叶子优先在小数据上略易过拟合 |

对本书读者来说，可以这样理解：**它们像同一道菜的两个菜谱，味道几乎一样，LightGBM 做得更快更省料**。实践中先用哪个都行，数据量大（几十万行以上）优先选 LightGBM，追求稳健和成熟生态选 XGBoost。两者的超参数含义高度一致，调参经验可以互相迁移。

**在因子投资中的最佳实践**：

| 超参数 | 推荐范围 | 原因 |
|--------|---------|------|
| 树的数量 | 500-2000 | 太少欠拟合，太多浪费计算 |
| 最大深度 | 3-6 | 浅树防过拟合（因子投资信噪比低） |
| 学习率 | 0.01-0.05 | 越小越稳健，但需要更多树 |
| 子采样率 | 0.7-0.9 | 类似随机森林的Bootstrap |
| 特征采样率 | 0.5-0.8 | 防止单个强因子主导 |

**关键教训**：在因子投资中，**浅树+低学习率+大量树**是最稳健的配置。原因是金融数据的信噪比极低（IC通常只有0.03-0.05），深树会把噪声当信号记住。

## 12.3 神经网络在因子投资中的应用

### 12.3.1 为什么用神经网络？

决策树系列方法擅长捕捉"阈值效应"（如EP>0.1时有效）和"低阶交互"（如EP×动量），但对高阶非线性关系的建模能力有限。神经网络通过多层非线性变换，理论上可以逼近任意复杂的函数，这是**万能逼近定理**（Universal Approximation Theorem）的结论。

但"理论上能逼近任意函数"和"实际中能学到有用的东西"之间隔着一道鸿沟。在因子投资的应用中，神经网络面临几个独特的挑战：

1. **数据量不够**：A股约5000只股票×120个月=60万条样本。这对图像识别来说微不足道（ImageNet有1400万张图），但对量化来说就是全部。
2. **信噪比极低**：股票收益中95%以上是噪声，有用信号可能只占1-5%。神经网络很容易把噪声当作模式记住。
3. **非平稳性**：过去学到的模式可能在未来不再成立（如2020年前的小市值效应在2020年后消失）。

### 12.3.2 前馈网络（MLP）在截面预测中的应用

最基础的应用是用多层感知器（MLP）替代线性回归做截面收益预测：

**模型结构**：
- 输入层：$K$ 个因子值（如20-50个因子）
- 隐藏层1：64个神经元，ReLU激活
- 隐藏层2：32个神经元，ReLU激活
- 输出层：1个神经元（预测收益），线性激活

**与线性模型的对比**：
- 线性模型：$\hat{r} = \sum_k w_k f_k$（$K$ 个参数）
- 2层MLP：$\hat{r} = W_3 \cdot \text{ReLU}(W_2 \cdot \text{ReLU}(W_1 \cdot \mathbf{f} + b_1) + b_2) + b_3$（约$K\times64 + 64\times32 + 32 = 64K + 2080$ 个参数）

当 $K=30$ 时，MLP有约4000个参数。用60万条数据训练4000个参数，自由度比看起来的充裕，但问题在于这60万条数据之间**不是独立的**（同一个月的3000只股票高度相关），有效独立样本可能只有几百个。

**防止过拟合的关键技术**：

1. **Dropout**：训练时随机关闭30-50%的神经元，迫使网络不依赖任何单一节点，类似于第6章中"不要把鸡蛋放在一个篮子里"
2. **L2正则化**：对权重的大小加惩罚（$\lambda \|W\|_2^2$），防止权重爆炸，本质上是贝叶斯先验"权重应该接近零"
3. **Early Stopping**：在验证集误差开始上升时停止训练，类似Walk-Forward中的"不能用未来数据"
4. **Batch Normalization**：标准化每层的输出，加速训练并有轻微的正则化效果

### 12.3.3 循环网络（LSTM）在时序预测中的应用

前馈网络处理的是"这个月的因子值→这个月的预测收益"（截面问题）。但如果你想利用**时间维度的信息**，比如"EP因子连续3个月有效"或"大盘连跌5天后通常反弹"，就需要能"记住过去"的网络结构。

**LSTM（Long Short-Term Memory）** 是处理序列数据的经典架构。它的核心是一个"记忆细胞"，通过三个"门"来控制信息的流入、保留和流出：

- **遗忘门**：决定"过去的信息有多少值得保留"（如：3个月前的动量信号还有效吗？）
- **输入门**：决定"这个月的新信息有多少值得记住"
- **输出门**：决定"记住的信息中有多少用于当前的预测"

**在量化中的典型应用**：

输入：过去12个月每个月的因子值向量（时间序列）
输出：下个月的预测收益

LSTM能捕捉到的模式（线性模型做不到的）：
- "因子动量"：如果EP因子连续3个月有效（IC>0），下个月很可能继续有效
- "市场状态切换"：如果过去2个月市场波动率急剧上升，因子关系可能发生质变
- "因子拥挤信号"：如果某因子收益连续下降，可能正在被过度套利

**实证表现**：学术研究（如Gu, Kelly & Xiu 2020[1]）发现，LSTM在美股截面收益预测中相比线性模型有约15-25%的IC提升。但在A股的效果不如美股稳定，A股的非平稳性更强，历史模式的"保质期"更短。

### 12.3.4 Transformer与注意力机制：最新前沿

Transformer是2017年后在NLP领域取得革命性成功的架构（GPT、BERT都基于它）。它的核心创新是**自注意力机制**（Self-Attention），让模型学习"当前应该关注输入序列中的哪个位置"。

**在量化中的潜在应用**：

1. **截面注意力**：3000只股票的因子值不是独立的，行业内的股票互相影响。Transformer可以学习"关注同行业其他股票的表现"来预测目标股票的收益
2. **时间注意力**：不是机械地用"过去12个月"，而是学习哪些历史时段与当前最相关（如"当前市场环境最像2018年Q4"）
3. **因子注意力**：不同市场环境下，不同因子的重要性不同。注意力权重自动调节

**当前状态**：Transformer在量化中的应用仍处于早期探索阶段。少数顶级量化机构（如Two Sigma、Citadel）可能已在内部使用，但公开的A股实证研究非常有限。对散户投资者而言，这目前是"了解方向但不建议实操"的领域。

## 12.4 机器学习在量化中的特殊挑战

### 12.4.1 过拟合：ML的头号敌人

在图像识别中，过拟合可以通过海量数据（数百万张图片）来缓解。但在量化投资中：
- 数据量有限（5000股票×120个月×20因子）
- 数据之间高度相关（同一月的股票不独立，相邻月份有自相关）
- 有效独立样本可能只有几百个

**经验法则**：如果你的模型在训练集上的IC=0.10，但在Walk-Forward样本外只有0.03，**你过拟合了**。ML模型在训练集上的表现通常会"虚高"2-5倍。

**防御方法**：
1. **时间序列交叉验证**：绝不在时间上前后打乱数据。训练集必须严格在验证集之前
2. **限制模型复杂度**：浅树、少参数、强正则化
3. **特征筛选**：不要把能找到的所有指标都扔进模型。先用第5章的IC检验筛选掉无效因子
4. **跨市场周期验证**：你的回测覆盖了完整的牛熊周期吗？如果只用 2019-2020 的牛市数据训练，模型学到的是"追涨就能赚钱"，在 2022 年熊市中会暴露全部问题。更务实的方法是：把回测数据按市场状态拆分（牛市期、熊市期、振荡期），检查策略在三个状态下是否都有正超额。如果只在牛市中赚钱，那不是一个多因子策略，只是一个加了杠杆的指数基金。
5. **考虑多策略配置**：同一个策略很难在所有市场状态下通吃。一个更鲁棒的方案是为不同市场状态准备不同的策略配置：牛市期重配动量和成长因子，熊市期重配低波动和价值因子，振荡期用等权或均值回归策略。然后用 §5.6 讨论过的因子拥挤度和 IC 趋势来判断当前市场处于什么状态，自动切换策略权重。这不是因子择时（择时的难度很高），而是用多个独立策略的组合来平抑周期波动。

### 12.4.2 非平稳性：过去不能代表未来

金融数据最恶心的特性：**规则会变**。

- 2017 年之前：小市值因子长期有效，是 A 股最强的因子之一
- 2017 年后：小市值因子大幅弱化（注册制改革消灭了壳价值，壳价值即A股IPO稀缺时期上市资格本身具有的价值）

如果你在 2017 年之前的数据上训练了一个高度依赖小市值信号的 ML 模型，它在 2017 年之后会彻底崩溃。而线性模型因为参数少、模式简单，受非平稳性的影响反而更小。

**应对策略**：
- **滚动重训练**：每月用最近60个月的数据重新训练模型，"忘掉"太久远的模式
- **特征重要性监控**：如果模型突然开始依赖某个以前不重要的因子，这是警报信号
- **集成多个时间窗口**：用6个月窗口训练一个模型、12个月窗口训练另一个、24个月再一个，最终取加权平均

### 12.4.3 可解释性：你信任一个你不理解的模型吗？

线性模型的优势之一是**完全可解释**：$\beta_k > 0$ 意味着因子$k$有正向预测力，大小代表效果强度。你能向投资委员会（或你自己）清楚地解释"为什么这个月超配银行股"。

而一个深层神经网络做出的决策，往往连模型的创建者都说不清楚。这带来两个实际问题：

1. **信任问题**：模型说"做空茅台"（做空即先卖出借来的股票，等跌了再买回归还），你敢执行吗？如果不理解原因，你很可能在亏损时恐慌覆盖
2. **监管问题**：机构投资者需要向监管机构解释投资决策的合理性。"因为模型说了"不是一个可接受的答案

**折中方案：可解释性工具**

- **SHAP值**（Shapley Additive Explanations）：为每只股票的每个因子分配一个"贡献度"，告诉你"这只股票被推荐做多，其中EP贡献了+0.3%，动量贡献了+0.2%，ROE贡献了-0.1%"
- **部分依赖图**（Partial Dependence Plot）：固定其他因子，只变化一个因子的值，观察预测收益如何变化，直观展示非线性关系的形状
- **特征重要性排序**：哪些因子对模型最重要？如果模型高度依赖一个你无法解释的因子，那值得警惕

## 12.5 另类数据：超越财务报表

### 12.5.1 什么是另类数据？

传统因子基于两类数据：**行情数据**（价格、成交量）和**财务数据**（利润表、资产负债表）。这两类数据所有投资者都能获取，信息优势有限。

另类数据（Alternative Data）是指传统数据之外的一切可用于预测股票收益的信息源：

| 类型 | 例子 | 可能的因子信号 |
|------|------|-------------|
| 文本数据 | 研报标题情绪、社交媒体情感 | 情绪因子 |
| 卫星图像 | 工厂/商场停车场卫星照片 | 经营活跃度因子 |
| 消费数据 | 信用卡交易流水汇总 | 收入增长预测因子 |
| 搜索/浏览 | 搜索引擎指数、电商浏览量 | 需求前瞻因子 |
| 供应链 | 海关进出口数据、航运指数 | 行业景气度因子 |

### 12.5.2 另类数据的核心价值：时效性

传统财务数据的最大问题是**滞后**：上市公司季报在季度结束后1个月才发布，年报要等4个月。当你看到"Q3盈利超预期"时，市场很可能已经反映了这个信息。

另类数据的优势是**实时性**。比如：
- 你在3月15日就能从卫星图像看到某工厂24小时灯火通明（产能爆满），而官方产能数据要等到4月中旬才发布
- 信用卡数据在消费发生当天就能获取，而公司营收数据要等下个季度才披露

这种"时间差"正是另类数据的alpha来源：**你比别人早知道基本面的变化**。

### 12.5.3 对A股散户投资者的现实建议

坦率地说，大部分另类数据对散户是**不可及的**：
- 卫星图像：国家安全限制
- 信用卡数据：只有与银行有合作的机构才能获取
- 企业级NLP模型：需要大量算力和工程资源

散户能合理利用的另类数据主要是：
- **公开文本数据**：研报评级变化、公告关键词（"业绩预增"vs"业绩预减"）
- **搜索指数**：搜索引擎（传统的如谷歌百度，现阶段或许还应加上小红书抖音等短社交平台，以及豆包等AI平台）反映的公众关注度
- **公开的宏观数据**：PMI、社融等（免费，但所有人都能看到）

我们的建议是：**先把传统因子做好（理论篇的内容），再考虑另类数据**。如果你的EP+动量+质量三因子组合都还没跑通，追求另类数据就是本末倒置。

## 12.6 ML在量化中的正确定位

### 12.6.1 ML不是"银弹"

很多人对ML有不切实际的期望，以为用了深度学习就能"战胜市场"。但真实情况是：

1. **ML不创造信息，只是更好地提取信息**。如果你的输入因子本身不含预测信号，再复杂的ML模型也提取不出有效预测
2. **ML对数据质量极其敏感**。"Garbage in, garbage out"在ML中比在线性模型中更严重，ML会把数据中的错误也当作"模式"学习
3. **最大的边际收益在"最后一公里"**。线性模型已经提取了因子的主要信息，ML 的额外提升通常来自非线性关系和交互效应的捕捉，边际增量是有限的。这有意义，但不是"颠覆性的"

### 12.6.2 一个务实的"分层"方法论

对于本书读者（有理工科背景的A股散户投资者），我们建议的ML使用路径分为三层，逐层递进：

| 层级 | 做什么 | 关键动作 | 判断标准 |
|------|-------|---------|---------|
| **第一层（基础）** | 先用纯线性方法把策略跑通 | ① 选定 EP + 动量 + 质量三因子<br>② 用 IC 加权合成综合得分<br>③ 按月度调仓（定期调整持仓）<br>④ 用第5章方法做 IC 检验和分层回测 | 样本外仍然有效，这一步就足以跑赢大部分散户 |
| **第二层（增强）** | 用随机森林/XGBoost 补充线性合成 | ① 保留线性合成作为主力<br>② 三因子值为输入、下月收益（或排名）为输出，训练树模型<br>③ 用 Walk-Forward 严格样本外验证（§5.5.5）<br>④ 树模型仅用于捕捉线性漏掉的非线性和交互效应 | 树模型样本外 IC 稳定优于线性方法时，才与线性预测做加权平均纳入，而非推翻线性框架 |
| **第三层（探索）** | 加入非线性因子和交互 | ① 用 SHAP 分析哪些因子交互最重要<br>② 尝试加入时序特征（如过去3个月 IC 的变化趋势）<br>③ 持续监控模型行为是否可解释 | 模型行为是否可解释，不可解释则不采用 |

**不建议**：
- 上来就用LSTM/Transformer（数据量不够、可解释性差）
- 用超过50个因子（维度灾难，大部分是噪声）
- 追求训练集IC最高（必然过拟合）

## 12.7 本章小结

### 12.7.1 内容回顾

1. **线性模型的天花板**在于无法捕捉非线性效应、因子交互和环境切换。ML提供了突破这个天花板的工具。

2. **随机森林和XGBoost**是因子投资中最实用的ML方法，既能捕捉非线性和交互，又不至于像深度网络那样容易过拟合。浅树+低学习率+强正则化是A股环境下的最佳配置。

3. **神经网络（MLP/LSTM/Transformer）**有更强的表达能力，但在当前A股数据量和信噪比条件下，过拟合风险很高。建议作为"探索方向"而非"主力武器"。

4. **ML在量化中最大的风险是过拟合和非平稳性**。Walk-Forward验证、滚动重训练、模型集成是必须的防御手段。

5. **另类数据**提供了超越传统因子的潜在信息优势，但对散户而言可及性有限。先把传统因子做好是正道。

6. **务实的路径**：线性模型打底（确保基础稳固）→ XGBoost增强（验证有增益再用）→ 深度模型探索（了解方向但不急于实操）。

量化投资正处于"从线性时代向ML时代过渡"的历史节点。我们这一代投资者的幸运在于：前人用30年时间建立的线性理论体系（本书前11章）仍然是有效的，ML不是替代它，而是在它的基础上更进一步。理解"为什么有效"仍然比"怎么调参"更重要。

### 12.7.2 常见陷阱

- **过度依赖复杂模型**：在数据量不足时使用LSTM/Transformer等深度模型，容易记住噪声而非信号。A股60万条样本对深度网络而言远远不够。
- **忽视样本外验证**：只看训练集IC就下结论，必然高估模型能力。ML模型训练集IC通常是样本外的2-5倍。
- **追逐另类数据而忽视基础因子**：如果EP+动量+质量三因子线性组合都未跑通，追求另类数据是本末倒置。
- **模型不做滚动重训练**：A股非平稳性强，过去有效的模式可能失效。必须每月或每季度用最近数据重新训练。
