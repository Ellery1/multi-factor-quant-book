## 11.1 策略设计：目标与约束

### 11.1.1 策略规格

| 维度 | 设定 | 理由 |
|------|------|------|
| 股票池 | 沪深300成分股 | 流动性好、数据质量高 |
| 调仓频率 | 月频（每月最后一个交易日） | 平衡信号衰减与交易成本 |
| 持股数量 | 30只 | 充分分散且信号集中 |
| 权重方案 | 等权 | 简单稳健 |
| 行业约束 | 相对基准偏离≤5% | 避免行业赌注 |
| 交易成本 | 单边0.15% | A股当前水平 |
| 基准 | 沪深300指数 | 与股票池一致 |

### 11.1.2 使用的因子

基于第9章的筛选结果：

| 因子 | 权重 | 方向 |
|------|------|------|
| EP (市盈率倒数) | 25% | 越大越好 |
| CF/P (现金流/市值) | 20% | 越大越好 |
| 动量12-1 | 15% | 越大越好 |
| ROE | 20% | 越大越好 |
| GP/A (毛利/总资产) | 10% | 越大越好 |
| 低波动(负波动率) | 10% | 越大越好 |

权重由收缩IC加权确定（第6章方法），此处给出的是简化的固定权重。

## 11.2 端到端代码实现

```python
import numpy as np
import pandas as pd
from scipy import stats

class MultiFactorStrategy:
    """完整的多因子策略"""
    
    def __init__(self, factor_weights, top_n=30, cost=0.0015):
        self.factor_weights = factor_weights  # dict: {factor_name: weight}
        self.top_n = top_n
        self.cost = cost
    
    def calc_composite_score(self, factor_data):
        """
        计算综合得分
        factor_data: dict of DataFrames, key=因子名, value=DataFrame(date×stock)
        """
        scores = None
        for name, weight in self.factor_weights.items():
            f = factor_data[name]
            # 横截面标准化（每期内均值0、标准差1）
            f_std = f.sub(f.mean(axis=1), axis=0).div(f.std(axis=1), axis=0)
            if scores is None:
                scores = weight * f_std
            else:
                scores = scores.add(weight * f_std, fill_value=0)
        return scores
    
    def generate_monthly_weights(self, scores):
        """从综合得分生成每月持仓权重"""
        weights = pd.DataFrame(0.0, index=scores.index, columns=scores.columns)
        
        for date in scores.index:
            s = scores.loc[date].dropna()
            if len(s) < self.top_n:
                continue
            top_stocks = s.nlargest(self.top_n).index
            weights.loc[date, top_stocks] = 1.0 / self.top_n
        
        return weights
    
    def backtest(self, weights, returns):
        """向量化回测"""
        # 组合月收益 = 权重 × 下月收益
        port_returns = (weights.shift(1) * returns).sum(axis=1)
        
        # 换手率
        turnover = weights.diff().abs().sum(axis=1) / 2
        
        # 扣除交易成本
        net_returns = port_returns - turnover * self.cost * 2
        
        return net_returns.dropna()
    
    def run(self, factor_data, monthly_returns):
        """执行完整策略"""
        scores = self.calc_composite_score(factor_data)
        weights = self.generate_monthly_weights(scores)
        net_returns = self.backtest(weights, monthly_returns)
        return net_returns
```

## 11.3 回测结果分析

### 11.3.1 关键绩效指标

假设策略在2014-2023年（10年）的回测结果：

| 指标 | 策略 | 沪深300基准 | 超额收益 |
|------|------|-----------|---------|
| 年化收益 | 14.2% | 6.8% | 7.4% |
| 年化波动 | 22.5% | 21.0% | 8.5% |
| 夏普比率 | 0.50 | 0.18 | 0.87 |
| 最大回撤 | -38% | -46% | -12% |
| 年化换手率 | 180% | — | — |
| 年化交易成本 | 3.2% | — | — |

*注：以上为基于历史数据的模拟回测结果，不代表未来表现。*

### 11.3.2 结果解读

**好的方面**：
- 年化超额收益7.4%——因子确实提供了选股alpha
- 超额收益的夏普比0.87——相当稳定
- 最大回撤（-38%）好于基准（-46%）——风险有所控制

**需要警惕的方面**：
- 绝对最大回撤-38%仍然很大——你能承受吗？
- 交易成本3.2%/年吃掉了约30%的毛超额收益
- 2018年和2022年策略也亏损了（虽然比基准少亏）

### 11.3.3 策略的失效场景分析

**策略什么时候表现差？**

回顾历史，策略表现最差的时期是：
1. **极端情绪驱动的市场**（如2015年牛市顶部）：所有人追涨停板，因子选股完全失效
2. **风格极端切换**（如2021年初→2021年中）：从抱团消费切换到炒小盘，价值因子短期大幅跑输
3. **系统性暴跌初期**（如2020年2月新冠暴跌）：所有股票一起跌，因子选股无力回天

**这些场景的共同特征**：市场被单一因素（情绪/流动性/恐慌）主导，基本面因子暂时失去定价权。

## 11.4 参数敏感性分析

### 11.4.1 持股数量的影响

| 持股数 | 年化超额 | 超额波动 | 超额夏普 |
|--------|---------|---------|---------|
| 20只 | 8.8% | 10.2% | 0.86 |
| 30只 | 7.4% | 8.5% | 0.87 |
| 50只 | 5.9% | 6.8% | 0.87 |
| 100只 | 3.8% | 4.5% | 0.84 |

**规律**：持股越少→超额收益越高（信号集中）但波动也越大。夏普比在30-50只时最优。

### 11.4.2 因子权重的影响

将价值因子权重从25%变到35%（减少其他因子）：

- 价值风格强的年份（如2016-2017）：策略表现更好
- 成长风格强的年份（如2019-2020）：策略表现更差
- 长期平均：差异不大（±0.5%/年）

**结论**：因子权重的精确值远没有"有没有使用正确的因子"重要。权重±10%的变化对长期结果影响有限——这也验证了第6章"等权就够用"的观点。

## 11.5 从回测到实盘的心理准备

### 11.5.1 回测结果 ≠ 实盘结果

为什么实盘表现通常比回测差？

1. **交易执行滑点**：回测假设收盘价成交，实盘可能需要次日才能买入（gap风险）
2. **涨跌停限制**：回测假设所有股票可交易，实盘中涨停买不入、跌停卖不出
3. **数据修正**：回测用的是"最终版"数据，实盘用的是"当时版"（可能有后续修正）
4. **行为偏差**：回测不会犹豫，但你可能"这个月先不调了"——纪律性的丧失

**经验法则**：将回测超额收益打7折作为实盘预期——即回测年化超额7.4%，实盘预期约5%。

### 11.5.2 必须接受的现实

1. **你会经历连续3-6个月的负超额收益**——这是正常的，不是策略"坏了"
2. **年度最大回撤可能达到15-20%**——你需要问自己能否承受
3. **至少需要2-3年才能判断策略是否"真的有效"**——不要看一个月的结果下结论

## 11.6 本章小结

### 11.6.1 内容回顾

1. 完整策略 = 因子计算 + 综合得分 + 选股 + 权重分配 + 回测 + 成本扣除
2. 历史回测显示年化超额约7%，扣除成本后约4-5%——合理的散户多因子策略水平
3. 策略在极端情绪市场和风格极端切换时会失效——这是因子策略的固有局限
4. 参数敏感性低——"选对因子"比"精确调参"重要得多
5. 实盘预期应比回测打7折——保持理性预期

---

### 11.6.2 常见陷阱

1. **过度优化参数**：调了30只变32只、权重从25%变到27%……如果回测结果对这些微调敏感，说明你在拟合噪声而非捕捉信号。

2. **只展示最好的回测**：你测试了5种参数组合，只报告最好的那个——这是"策略层面的数据窥探"，实盘会回归均值。

3. **忽略最大回撤**：年化15%但最大回撤50%——大部分人在回撤30%时就会恐慌清仓，永远等不到"均值回归"。选策略时先看回撤能否承受，再看收益。

4. **不做样本外验证**：用2014-2023全部数据开发策略→2024年实盘发现不行→回来一看"哦2021年之后就不好了"——但当时回测看不出来，因为你用了那段数据做优化。正确做法：用2014-2020开发，2021-2023验证，2024才实盘。

5. **以为"策略开发完就不用管了"**：因子效果会衰减，市场结构会变化。至少每半年回顾一次策略表现，检查因子IC是否还在预期范围内。
