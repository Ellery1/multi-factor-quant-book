## 10.1 从因子得分到股票排名

### 10.1.1 综合得分的计算

使用第6章的合成方法（假设用收缩IC加权），每月底得到每只股票的综合得分：

$$S_i = w_1 \cdot \tilde{f}_{1i} + w_2 \cdot \tilde{f}_{2i} + ... + w_K \cdot \tilde{f}_{Ki}$$

其中 $\tilde{f}_{ki}$ 是标准化后的因子值，$w_k$ 是第6章确定的因子权重。

### 10.1.2 选股数量的确定

**选多少只？** 这取决于两个考量：

1. **分散化需要**：持股越多，个股特异风险越低。30只以上基本够用（特异风险降到10%以下）。
2. **信号强度衰减**：排名越靠后，因子信号越弱。买前100只比买前30只的平均得分低→组合的"因子暴露"更弱。

**经验法则**：对于沪深300选股，持有30-50只是合理范围。

## 10.2 权重分配方案

### 10.2.1 等权（Equal Weight）

$$w_i = \frac{1}{N}, \quad \text{for all selected stocks}$$

**优点**：
- 最简单，不需要额外估计
- 最大程度分散——对每只股票的依赖相同
- 不受市值偏见影响

**缺点**：
- 忽略了因子得分差异（得分0.95和得分0.50的股票权重相同）
- 小盘股流动性差，等权买入可能有冲击成本问题

**适合散户吗？** 非常适合。等权策略对于5-50万的散户资金没有流动性问题，且实操最简单。

### 10.2.2 得分加权（Score-Weighted）

$$w_i = \frac{S_i}{\sum_{j \in \text{selected}} S_j}$$

权重正比于因子得分——得分越高买的越多。

**优点**：信号更强的股票给予更大权重→组合的因子暴露更强→预期alpha更高

**缺点**：过度集中在少数高分股票→如果某只高分股暴雷，影响巨大

### 10.2.3 市值加权（Cap-Weighted）

$$w_i = \frac{\text{MarketCap}_i}{\sum_{j \in \text{selected}} \text{MarketCap}_j}$$

**优点**：交易冲击最小（大股票流动性好）；与指数贴近（跟踪误差小）

**缺点**：本质上是向"大市值"因子暴露——与你的因子选股逻辑可能冲突

### 10.2.4 三种方案的实际对比

| 方案 | 预期alpha | 波动率 | 换手率 | 最大单股权重 | 推荐场景 |
|------|----------|--------|--------|------------|---------|
| 等权 | 中等 | 较低 | 中等 | 3.3%（30只） | 散户首选 |
| 得分加权 | 较高 | 较高 | 较高 | 可能>10% | 信号很强时 |
| 市值加权 | 较低 | 最低 | 最低 | 可能>15% | 大资金/控风险 |

**推荐**：散户用等权起步。如果因子的IR > 1.0且你对信号有高度信心，可以尝试得分加权。

## 10.3 约束条件设计

### 10.3.1 行业中性约束

**问题**：如果不控制行业，你的"价值策略"可能全选了银行股——表面上在做因子选股，实际在做行业赌注。

**解决方案**：限制每个行业的权重不超过基准权重的±5%。

```python
def apply_industry_neutral(weights, industry_map, benchmark_weights, max_dev=0.05):
    """行业中性化约束"""
    for ind in industry_map.unique():
        stocks_in_ind = industry_map[industry_map == ind].index
        port_weight = weights[stocks_in_ind].sum()
        bench_weight = benchmark_weights[stocks_in_ind].sum()
        
        # 如果组合在该行业的超配超过阈值，按比例削减
        if port_weight - bench_weight > max_dev:
            scale = (bench_weight + max_dev) / port_weight
            weights[stocks_in_ind] *= scale
    
    # 重新归一化
    weights = weights / weights.sum()
    return weights
```

### 10.3.2 个股上限约束

**目的**：防止单只股票权重过大（如果该股票暴跌30%你的组合损失就太大了）。

**常见设置**：单股权重不超过5%（等权30只时自然满足——每只3.3%）。

### 10.3.3 最小持仓约束

如果某只股票权重算出来只有0.3%——实际上5万元的组合中这只股票只占150元——买不到一手（A股最少买100股）。

**处理方式**：设置最低权重阈值（如1%），低于阈值的不买，权重重新分配给其他股票。

## 10.4 换手率控制

### 10.4.1 为什么换手率重要？

每次调仓都有交易成本（约0.15%单边）。如果你每月把组合翻一遍（100%换手率），年化成本：

$$\text{年化成本} = 12 \times 100\% \times 0.15\% \times 2 = 3.6\%$$

如果因子年化溢价只有8%，成本就吃掉了45%——非常可观。

### 10.4.2 降低换手率的方法

**方法1：缓冲区（Buffer）**

不是"得分前30名买入、第31名卖出"，而是设置缓冲区：
- 进入规则：得分进入前25名才买入
- 退出规则：得分跌出前35名才卖出

中间地带（25-35名）维持现有持仓不动——避免在"边界上"频繁进出。

**方法2：部分调仓**

每月只调整1/3的仓位——不是一次性从旧组合切换到新组合，而是用3个月逐步过渡。

$$w_{\text{actual}} = \frac{2}{3} w_{\text{previous}} + \frac{1}{3} w_{\text{target}}$$

**方法3：增加换手率惩罚**

在优化目标中直接加入换手率成本：

$$\max_w \quad w^T \mu - \frac{\gamma}{2}w^T\Sigma w - \lambda \cdot \|w - w_{\text{prev}}\|_1$$

最后一项惩罚"偏离前一期权重"的程度——$\lambda$ 越大，调仓越少。

## 10.5 完整的组合构建代码

```python
def build_portfolio(factor_scores, prev_weights=None, 
                    top_n=30, max_single=0.05, buffer=5,
                    turnover_penalty=0.3):
    """
    从因子得分构建持仓权重
    """
    scores = factor_scores.dropna().sort_values(ascending=False)
    
    if prev_weights is None:
        # 首次建仓：直接选top_n
        selected = scores.head(top_n).index
    else:
        # 有缓冲区的换仓逻辑
        current_holdings = prev_weights[prev_weights > 0].index
        new_top = scores.head(top_n - buffer).index  # 新进入门槛更严
        exit_threshold = scores.head(top_n + buffer).index  # 退出门槛更宽
        
        # 保留：当前持有且未跌出退出门槛的
        keep = current_holdings.intersection(exit_threshold)
        # 新增：进入新top但之前未持有的
        add = new_top.difference(current_holdings)
        # 合并（控制总数不超过top_n + buffer/2）
        selected = keep.union(add)[:top_n + buffer//2]
    
    # 等权分配
    weights = pd.Series(1.0/len(selected), index=selected)
    
    # 个股上限
    weights = weights.clip(upper=max_single)
    weights = weights / weights.sum()  # 归一化
    
    return weights
```

## 10.6 本章小结

### 10.6.1 内容回顾

1. 等权是散户最佳起点——简单、分散、不受市值偏见
2. 行业中性约束防止"伪装成因子选股的行业赌注"
3. 换手率控制至关重要——缓冲区和部分调仓是两个实用技巧
4. 从因子得分到最终持仓：选股（top N）→ 分配权重 → 施加约束 → 换手控制

---

### 10.6.2 常见陷阱

1. **追求"最优"权重而忽略稳健性**：均值方差优化看似理论最优，但对输入参数（预期收益、协方差矩阵）极其敏感。散户用等权就够了。

2. **不控制行业导致"假因子暴露"**：你以为买的是"便宜好公司"，实际上全是银行股——一旦银行板块整体回调你就完蛋。

3. **忽视换手成本**：优化器算出来的"最优组合"可能每月换手150%——交易成本5%+/年，吃掉全部alpha。

4. **持股太少**：只买10只股票的组合波动极大，因子收益可能被个股噪声淹没。至少30只以确保分散化。
