## 写作原则

- 理论优先：以严密逻辑推导为主线，代码仅作验证辅助
- 代码占比 ≤ 25%
- 每章 8000-18000 字
- 使用 Python 作为唯一编程语言
- 基于 A 股（沪深300）真实数据案例
