## 7.2 数据清洗：隐藏的陷阱

数据清洗是量化研究中最容易出错但最不受重视的环节。**错误的数据 → 错误的因子 → 错误的结论**。

### 7.2.1 复权处理

股票发生除权除息（分红、送股、配股）后，价格会"跳空"。如果不做复权处理，计算出的收益率会严重失真。

**例子**：某股票除息前收盘30元，每股分红1元，除息日开盘29元。
- 不复权：收益率 = (29-30)/30 = -3.3%（看似亏了）
- 前复权后：连续价格序列不会出现跳空，收益率反映真实涨跌

**原则**：计算收益率时**必须使用复权价格**。推荐使用前复权（`adj_close`），这样最新价格是真实的，历史价格被调整。

```python
# Tushare的复权行情接口
df_adj = pro.daily(ts_code='000001.SZ', adj='qfq',  # qfq=前复权
                   start_date='20210101', end_date='20231231')
```

### 7.2.2 停牌和涨跌停处理

**停牌**：股票停牌期间无成交。处理方式：
- 计算收益率时，跳过停牌日（停牌日收益率记为NaN或0）
- 回测时，停牌股票不能买入也不能卖出——需要在调仓日检查可交易性

**涨跌停**：涨停的股票通常买不进去（封死），跌停的股票卖不出去。
- 回测时：调仓日涨停的股票不能买入，跌停的股票不能卖出
- 这是A股特有的实盘约束——不处理会高估策略收益

### 7.2.3 幸存者偏差

**定义**：只用"现在还活着"的股票做回测，忽略了历史上已退市的股票。

**危害**：退市的往往是"最差"的公司——如果你的因子选中了这些"看似便宜"的股票（实际上快要退市），真实回报是-100%。但由于幸存者偏差，你的回测中看不到这些亏损。

**解决方案**：使用"时点数据"——在每个历史时刻，只使用**当时存在**的股票（包括后来退市的）。Tushare的数据天然包含退市股票信息。

### 7.2.4 财报数据的时间对齐

**核心问题**：财报有"报告期"和"实际发布日"的区别。

- 2023年年报的报告期是2023年12月31日
- 但实际发布日可能是2024年3月15日
- 如果你在2024年2月1日的回测中使用了这份年报数据→**前视偏差**！

**正确做法**：用`实际公告日期`来确定数据何时可用，而非`报告期末日期`。

```python
# 获取财报公告日期
disclosure = pro.disclosure_date(ts_code='000001.SZ', end_date='20231231')
# 用actual_date(实际公告日)而非end_date(报告期)来确定数据可用时间
```

## 7.3 数据存储方案

对于散户的月频多因子策略，数据量不大（沪深300×3年日频 ≈ 20万行），存储选择无需过度考虑：

| 方案 | 适合场景 | 优点 | 缺点 |
|------|---------|------|------|
| CSV文件 | 最简单，入门首选 | 无需额外安装 | 查询慢，不适合大数据 |
| Parquet文件 | 数据量稍大时 | 压缩好、读取快 | 需安装pyarrow |
| SQLite | 需要频繁查询时 | 支持SQL查询、无服务器 | 写入稍慢 |

**推荐**：先用CSV入门，数据量增大后迁移到Parquet。

## 常见陷阱

1. **不做复权就算收益率**：除权后价格"跳水"会被误认为亏损。所有收益率计算必须基于复权价。

2. **用报告期而非公告日做数据对齐**：一季报的报告期是3月31日，但可能4月底才发布。回测中3月31日就用了这个数据=前视偏差。

3. **忽略幸存者偏差**：只用当前在上市的股票回测，忽略了已退市公司——高估了策略收益（尤其影响小市值和价值因子）。

4. **数据频率不匹配**：用日频行情计算的动量因子，去预测月频的收益率——时间频率要匹配，否则结论不可靠。
