## 8.1 回测引擎的设计思路

### 8.1.1 什么是回测？

回测 = **用历史数据模拟"如果过去按某个策略投资，结果会怎样"**。

核心循环：
```
for 每个调仓日 t:
    1. 用t时刻之前的数据计算因子值
    2. 根据因子值确定目标持仓（买哪些、各买多少）
    3. 从当前持仓调整到目标持仓（卖出旧的、买入新的）
    4. 记录从t到下一个调仓日的组合收益
```

### 8.1.2 向量化 vs 事件驱动

两种主流的回测架构：

| | 向量化回测 | 事件驱动回测 |
|--|-----------|------------|
| 核心思想 | 用矩阵运算一次性算出所有期的收益 | 逐日/逐笔模拟交易过程 |
| 速度 | 极快（秒级） | 慢（分钟到小时级） |
| 精度 | 月频足够准确 | 可模拟日内细节 |
| 复杂度 | 简单（~200行代码） | 复杂（~2000行+） |
| 适用 | 月频多因子策略（本书重点） | 日内/高频策略 |

**本书选择向量化回测**——因为月频多因子策略不需要日内细节，而向量化方案简单、快速、不容易出bug。

### 8.1.3 核心设计决策

我们做以下简化假设：
- 调仓频率：月频（每月最后一个交易日调仓）
- 交易执行：以调仓日收盘价成交（实际中会有滑点，第15章讨论）
- 交易成本：单边0.15%（含佣金+印花税的简化）
- 现金管理：不持有现金，全仓投入

## 8.2 向量化回测的核心实现

### 8.2.1 数据结构

```python
import numpy as np
import pandas as pd

class BacktestEngine:
    """简单的向量化回测引擎"""
    
    def __init__(self, returns, cost_rate=0.0015):
        """
        参数:
            returns: DataFrame, index=日期, columns=股票代码, values=日收益率
            cost_rate: 单边交易成本率
        """
        self.returns = returns
        self.cost_rate = cost_rate
    
    def run(self, weights):
        """
        执行回测
        参数:
            weights: DataFrame, index=调仓日期, columns=股票代码, values=持仓权重
                     每行权重之和应为1（满仓）
        返回:
            DataFrame with columns: ['portfolio_return', 'turnover', 'cost']
        """
        results = []
        
        # 获取所有调仓日期
        rebalance_dates = weights.index.tolist()
        
        for i in range(len(rebalance_dates) - 1):
            date_start = rebalance_dates[i]
            date_end = rebalance_dates[i + 1]
            
            # 当期权重
            w = weights.loc[date_start]
            
            # 当期各股票收益（从调仓日到下一个调仓日）
            period_returns = self.returns.loc[date_start:date_end].iloc[1:]  # 排除调仓当日
            
            # 组合日收益 = 权重 × 个股收益之和
            portfolio_daily = period_returns.multiply(w, axis=1).sum(axis=1)
            
            # 换手率 = |新权重 - 旧权重（经过收益率漂移后）|
            if i == 0:
                turnover = w.abs().sum()  # 第一期全部买入
            else:
                # 上期权重经过持有期收益后的"漂移权重"
                prev_w = weights.loc[rebalance_dates[i-1]]
                period_ret = (1 + self.returns.loc[rebalance_dates[i-1]:date_start].iloc[1:]).prod() - 1
                drifted_w = prev_w * (1 + period_ret)
                drifted_w = drifted_w / drifted_w.sum()  # 重新归一化
                turnover = (w - drifted_w).abs().sum() / 2  # 单边换手率
            
            # 交易成本
            cost = turnover * self.cost_rate * 2  # 双边成本
            
            # 记录
            for date, ret in portfolio_daily.items():
                results.append({
                    'date': date,
                    'gross_return': ret,
                    'turnover': turnover / len(portfolio_daily),  # 分摊到每日
                    'cost': cost / len(portfolio_daily)
                })
        
        result_df = pd.DataFrame(results).set_index('date')
        result_df['net_return'] = result_df['gross_return'] - result_df['cost']
        return result_df
```

### 8.2.2 绩效指标计算

```python
def calc_metrics(daily_returns, rf=0.03/252):
    """计算策略的关键绩效指标"""
    
    # 年化收益率
    total_return = (1 + daily_returns).prod() - 1
    n_years = len(daily_returns) / 252
    annual_return = (1 + total_return) ** (1/n_years) - 1
    
    # 年化波动率
    annual_vol = daily_returns.std() * np.sqrt(252)
    
    # 夏普比率
    sharpe = (annual_return - rf*252) / annual_vol
    
    # 最大回撤
    cumulative = (1 + daily_returns).cumprod()
    running_max = cumulative.cummax()
    drawdown = cumulative / running_max - 1
    max_drawdown = drawdown.min()
    
    # Calmar比率 = 年化收益 / 最大回撤
    calmar = annual_return / abs(max_drawdown) if max_drawdown != 0 else np.inf
    
    return {
        'annual_return': f"{annual_return:.2%}",
        'annual_volatility': f"{annual_vol:.2%}",
        'sharpe_ratio': f"{sharpe:.2f}",
        'max_drawdown': f"{max_drawdown:.2%}",
        'calmar_ratio': f"{calmar:.2f}",
    }
```

## 8.3 回测偏差来源分析

### 8.3.1 前视偏差（Look-Ahead Bias）

**定义**：在时刻 $t$ 的决策中使用了时刻 $t$ 之后才能获得的信息。

**常见形式**：
- 用尚未公布的财报数据计算因子
- 用当期收盘价计算因子后"立刻"以该收盘价成交（实际上你得等到下一天才能交易）
- 用经过后续数据修正过的"修正值"做历史回测

**防范措施**：在代码中严格执行"时间戳检查"——每个数据点都标注"什么时候可用"。

### 8.3.2 幸存者偏差（Survivorship Bias）

详见第7章7.2.3节。核心：必须包含已退市股票。

### 8.3.3 交易成本忽略

不算交易成本的回测就像不考虑摩擦力的物理模型——理论上优雅但实际中可能完全不成立。

**A股成本构成**：
- 佣金：约0.02-0.03%（券商竞争已非常充分）
- 印花税：卖出时0.05%（2023年减半后）
- 滑点/冲击：约0.05-0.1%（取决于股票流动性和下单规模）
- 合计单边：约0.1-0.15%

对于月度调仓、双边换手率100%的策略：年化交易成本 ≈ 0.15% × 2 × 12 ≈ 3.6%。这不是小数——如果你的因子年化溢价只有6%，交易成本就吃掉了60%！

## 8.4 完整回测流程示例

```python
# === 完整的月频多因子回测流程 ===

# 1. 准备数据（假设已有月频因子值和日频收益率）
# factor_scores: DataFrame, index=月末日期, columns=股票代码, values=综合因子得分
# daily_returns: DataFrame, index=交易日, columns=股票代码, values=日收益率

# 2. 生成每月持仓权重（等权买入得分最高的30只）
def generate_weights(factor_scores, top_n=30):
    weights_dict = {}
    for date in factor_scores.index:
        scores = factor_scores.loc[date].dropna()
        top_stocks = scores.nlargest(top_n).index
        w = pd.Series(1.0/top_n, index=top_stocks)
        weights_dict[date] = w
    return pd.DataFrame(weights_dict).T.fillna(0)

weights = generate_weights(factor_scores)

# 3. 运行回测
engine = BacktestEngine(daily_returns, cost_rate=0.0015)
result = engine.run(weights)

# 4. 计算绩效
metrics = calc_metrics(result['net_return'])
print(metrics)
```

## 8.5 本章小结

1. 向量化回测适合月频多因子策略——简单快速不易出错
2. 核心循环：计算因子→确定权重→模拟持有收益→扣除成本
3. 三大偏差来源：前视偏差、幸存者偏差、忽略交易成本
4. A股月频策略的交易成本约3-4%/年——不可忽略

## 常见陷阱

1. **调仓日当天的收益率算入策略**：月底计算因子后以收盘价"成交"——但该收盘价对应的当日收益率不应计入（你还没持有这些股票）。应从T+1日开始计算。

2. **不检查股票可交易性**：某只股票在调仓日涨停（买不进）或停牌（无法交易）——回测中默认"能成交"高估了策略表现。

3. **权重不归一**：如果持有的某些股票退市或停牌，剩余股票的权重之和不再为1——需要重新归一化或用现金补齐。

4. **忽略再平衡时的"漂移"**：月初等权买入30只股票，月末有些涨有些跌——实际权重已经不再等权。计算换手率时要基于"漂移后的实际权重"而非"上次的目标权重"。
