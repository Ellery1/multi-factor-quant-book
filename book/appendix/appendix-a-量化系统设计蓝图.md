# 附录A：量化系统技术设计方案示例

> 本附录将正文中讨论的所有方法论和技术环节组织成一套完整的系统设计方案。每个模块都标注了对应的正文章节，方便读者在看到某个模块时快速回溯理论依据。如果你具备一定的代码能力，想跳过数学推导直接搭系统，可以从这里开始；如果你已经读完全书想做工程落地，这里是你的施工图纸。

## A.4 因子生命周期管理流程

一个因子从"候选"到"退役"的完整管理流程：

```
┌───────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐   ┌───────────┐
│ 理论提出   │──→│ 数据验证   │──→│ 入选组合   │──→│ 持续监控   │──→│ 退役/降权  │
│           │   │           │   │           │   │           │   │           │
│ 经济学逻辑 │   │ IC/IR/t值 │   │ 确定权重   │   │ IC半衰期  │   │ 溢价衰竭   │
│ DDM/APT   │   │ 分层单调性 │   │ 正交化后   │   │ 拥挤度    │   │ 制度变化   │
│ 信息扩散   │   │ 样本外有效 │   │ 合成为得分 │   │ 持续性系数 │   │ (如注册制) │
│           │   │           │   │           │   │           │   │           │
│ §3.3,§4.x │   │ §5.2-§5.5 │   │ §6.2-§6.6 │   │ §3.5.2-3  │   │ §3.5.3    │
└───────────┘   └───────────┘   └───────────┘   └───────────┘   └───────────┘

关键判定阈值：
· 入选条件：IC均值>0.02, IR>0.4, t>3(多重检验调整后), 经济学解释明确
· 降权信号：滚动12月IC均值下降50%以上，或IC持续性系数ρ下降至<0.3
· 退役条件：IC均值归零且持续12个月以上，或底层逻辑失效（如壳价值因子在注册制后）
· 衰减模型（§3.5.3）：λ(t) = (λ₀ - λ∞)·e^{-κt} + λ∞，半衰期 = ln2/κ
```

## A.7 关键算法实现速查表

以下表格汇总了正文中所有需要写代码实现的核心算法，标注了章节引用、推荐库和实现要点。

| 步骤 | 核心算法 | 章节 | 推荐实现 | 关键要点 |
|------|---------|------|---------|---------|
| 去极值 | Winsorize 1%/99% | §5.1, §8.1.2 | `scipy.stats.mstats.winsorize` | 按月横截面操作 |
| 行业中性化 | 行业内 z-score | §8.1.2 | `groupby('industry').transform` | 申万一级31个行业 |
| 市值正交化 | OLS回归取残差 | §8.1.3 | `statsmodels.api.OLS` | 加截距项，自变量为log(mv) |
| IC计算 | Spearman秩相关 | §5.2.1 | `scipy.stats.spearmanr` | 排除缺失值后计算 |
| IC显著性 | t = IC均值×√T / σ_IC | §5.2.5 | 手动计算 | T为月数，t>3视为显著 |
| 多重检验 | Bonferroni / BH-FDR | §5.5.2 | `statsmodels.stats.multitest` | 候选因子数决定门槛 |
| 正交化 | 对称正交化 Σ^{-1/2} | §6.4 | `scipy.linalg.sqrtm` | 输入为因子相关矩阵 |
| 协方差收缩 | Ledoit-Wolf | §6.6.2 | `sklearn.covariance.LedoitWolf` | 自动确定收缩强度 |
| 因子合成 | w* ∝ Σ⁻¹μ | §6.3 | `np.linalg.solve(Sigma, mu)` | 用收缩后的Σ |
| 缓冲区 | 进入/退出双阈值 | §8.4.2 | 逻辑判断 | 进入≤Top25, 退出>Top35 |
| 换手率计算 | 漂移后权重差额 | §7.4.2 | 手动计算 | 上期权重×(1+持有期涨幅)后归一化 |
| Walk-Forward | 滚动窗口训练/预测 | §5.5.5 | 循环实现 | 固定窗口，每步前滚1期 |
| DSR | Deflated Sharpe Ratio | §10.2.2 | 手动实现 | 输入：观测SR、试验数M、偏度、峰度 |
| VaR | 正态法/历史模拟法 | §9.1.2 | 手动计算 | z_95%=1.645, z_99%=2.326 |
| 冲击成本 | 平方根模型 | §3.5.2, §11.2.2 | 手动计算 | η·σ·√(V_trade/ADV) |
| 因子衰减 | 指数衰减模型 | §3.5.3 | 手动计算 | λ(t)=(λ₀-λ∞)·e^{-κt}+λ∞ |
| ROE持续性 | AR(1)半衰期 | §4.3.4 | `statsmodels.tsa.AR` | t½ = -ln2/ln(ρ) |
| 动量崩溃风险 | 组合净beta监控 | §4.2.5 | 手动计算 | β_MOM = β_W - β_L < 0 时警惕反弹 |

## A.9 主程序入口示例

```python
"""
月度调仓完整入口（对应 §8.5.2 策略执行流程）
"""
import yaml
from data_pipeline.normalizer import standardize_raw_data
from data_pipeline.adjuster import apply_forward_adjustment
from data_pipeline.filter import remove_special_stocks
from data_pipeline.aligner import align_financial_dates
from factors.preprocessing import preprocess_all_factors
from factors.orthogonalization import symmetric_orthogonalize
from factors.testing import compute_monthly_ic
from strategy.synthesis import synthesize_scores
from strategy.portfolio import build_target_portfolio
from strategy.rebalance import apply_buffer_rule
from strategy.executor import check_tradability, generate_orders, log_trades
from risk.metrics import compute_drawdown
from risk.decay_monitor import check_ic_health
from risk.alert import send_alert_if_needed


def monthly_rebalance(date: str, config: dict):
    """
    每月调仓的完整入口。
    对应流程图 A.2 的步骤 ①-⑮。
    """
    # ① 数据更新（§7.1.3 增量拉取）
    standardize_raw_data(date)
    apply_forward_adjustment(date)          # §7.2.1 复权

    # ② 股票池确定（§8.1.3）
    universe = remove_special_stocks(date)  # 剔除ST/次新/停牌

    # ③ 因子计算 + ④ 预处理（§4.1-§4.4, §8.1.2）
    # 对齐财报日期防止前视偏差（§7.2.4）
    align_financial_dates(date)
    factors = preprocess_all_factors(universe, date)

    # ⑤ 正交化（§6.4）
    factors_orth = symmetric_orthogonalize(factors)

    # ⑥ 因子合成（§6.2-§6.6）
    method = config["strategy"].get("synthesis_method", "shrinkage_ic")
    scores = synthesize_scores(factors_orth, method=method)

    # ⑦⑧ 综合得分排名 + 选股（§8.3.3）
    top_n = config["strategy"]["top_n"]

    # ⑨ 缓冲区过滤（§8.4.2）
    buffer = config["strategy"]["buffer"]
    target_stocks = apply_buffer_rule(
        scores, top_n,
        entry=buffer["entry_threshold"],
        exit=buffer["exit_threshold"]
    )

    # ⑩⑪ 权重分配 + 约束检查（§8.3.4-§8.3.5）
    target_portfolio = build_target_portfolio(
        target_stocks, scores,
        weight_scheme=config["strategy"]["weight_scheme"],
        constraints=config["strategy"]["constraints"]
    )

    # ⑫ 可交易性检查（§7.2.2）
    tradable_portfolio = check_tradability(target_portfolio, date)

    # ⑬ 生成订单（§7.3.3）
    orders = generate_orders(tradable_portfolio, date, config["cost"])

    # ⑭ 记录日志
    log_trades(orders)

    # ⑮ 风险检查（§9.1, §10.4, §3.5.3）
    compute_drawdown(date)
    check_ic_health(factors, date)          # IC半衰期监控
    send_alert_if_needed(config["risk"])


if __name__ == "__main__":
    with open("config/settings.yaml") as f:
        config = yaml.safe_load(f)

    # 获取回测区间内的所有调仓日
    from utils.calendar import get_rebalance_dates
    dates = get_rebalance_dates(
        config["backtest"]["start_date"],
        config["backtest"]["end_date"],
        freq=config["strategy"]["rebalance_freq"]
    )

    for date in dates:
        monthly_rebalance(date, config)
```
